# Tarification-de-la-prime-pure-en-assurance-automobile
Construction d'un modèle de tarification de prime pure (Prime pure estimée = fréquence estimée * sévérité estimée) pour un portefeuille automobile en modélisant séparément la fréquence et la sévérité . Après comparaison de plusieurs approches, on en ressort le modèle garantissant la meilleure précision d'estimation de cette prime pure
